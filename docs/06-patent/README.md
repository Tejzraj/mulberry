# 06 - Intellectual Property and Patent Research

This directory contains research documentation exploring the intellectual property landscape, prior-art search protocols, proposed technical concepts, and legal evaluation frameworks for the smart mulberry cutting machine project.

## Document Index

1. [`innovation-concept.md`](innovation-concept.md) — Rigorous technical description of the proposed concepts, technical interactions, experimental demonstration requirements, and inventive-step questions.
2. [`patentable-elements.md`](patentable-elements.md) — Categorization of proposed hardware, algorithmic, and control interactions under patent statutory guidelines (e.g., Indian Patents Act Section 3(k) restrictions on software per se).
3. [`prior-art.md`](prior-art.md) — Global prior-art tracking table covering agricultural cutters, chaff cutters, vision-based sorting, and sericultural implements.
4. [`patent-research-plan.md`](patent-research-plan.md) — Search strategy, IPC/CPC classification codes, boolean query strings, and search engine methodologies (WIPO Patentscope, Google Patents, InPASS).

## Critical IP & Legal Disclaimer

> [!IMPORTANT]
> **No Claim of Patentability**: Nothing in this repository constitutes a claim that any feature, algorithm, or mechanism is patentable, novel, or free from infringement risks.
> **Formal Legal Assessment Required**: **Patentability requires a formal prior-art and legal assessment** conducted by registered patent agents or intellectual property attorneys after reproducible experimental validation.
> All features and technical interactions documented herein are strictly **proposed concepts** under active engineering research.
