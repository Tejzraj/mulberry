# 02 - Sericulture Knowledge Base

This directory documents the sericultural process, silkworm (*Bombyx mori*) biology, instar-specific development, rearing practices, environmental demands, and feed requirements.

## Document Index

1. [`sericulture-overview.md`](sericulture-overview.md) — Definition, economic context, mulberry vs. non-mulberry sericulture, and production stages.
2. [`silkworm-life-cycle.md`](silkworm-life-cycle.md) — Metamorphosis stages: Egg, Larva (instars), Pupa (cocoon), and Adult moth.
3. [`silkworm-instars.md`](silkworm-instars.md) — Detailed larval stages (1st to 5th instar), ecdysis (moulting), and anatomical changes.
4. [`silkworm-rearing.md`](silkworm-rearing.md) — Rearing methodologies (tray rearing, shoot rearing, shelf rearing) and bed cleaning practices.
5. [`feeding-requirements.md`](feeding-requirements.md) — Instar-wise feeding schedules, leaf size specifications, consumption rates, and machine implications.
6. [`rearing-environment.md`](rearing-environment.md) — Temperature, relative humidity, air circulation, and lighting requirements across stages.
7. [`silkworm-diseases.md`](silkworm-diseases.md) — Pebrine, Flacherie, Grasserie, and Muscardine; etiology and sanitation requirements.
8. [`cocoon-production.md`](cocoon-production.md) — Maturation, spinning, mounting frames (chandrike), harvesting, and commercial quality parameters.

## Core Research Objective

To establish precise, evidence-backed feed preparation parameters (particle geometry, edge cleanliness, moisture maintenance) dictated by the biological eating capabilities of *Bombyx mori* at each developmental stage.
