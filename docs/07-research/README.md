This directory formalizes the scientific methodology, core investigative questions, experimental test protocols, and verified academic/institutional bibliography underpinning the smart mulberry cutting machine project.

## Research Principles
- **Evidence Before Claims**: No engineering assertion is valid without reproducible empirical data or primary peer-reviewed literature.
- **Fact vs. Hypothesis**: Theoretical models and proposed concepts remain explicitly demarcated as *unvalidated hypotheses* until benchmarked.
- **Integrity of Citations**: No artificial URLs, DOI records, or author names are tolerated. Any unverified citation is clearly designated as `Source required`.
