# Daily Engineering & Research Reports

This directory houses the chronological record of daily engineering activities, literature findings, experimental observations, design decisions, and Git commit references for the **Mulberry Smart Cutting Machine** project.

## Daily Reporting Standard

Every working day concludes with an updated or newly created report following the naming convention:
`daily-reports/YYYY-MM-DD.md`

### Mandatory Report Structure
1. **Objective**: Primary target of the day's work.
2. **Work Completed**: Granular bullet points of tasks executed, documentation created, code implemented, or experiments run.
3. **Key Understanding**: Scientific or engineering insights gained during the day.
4. **Open Questions**: Uncertainties, trade-offs, or blockers encountered.
5. **Next Steps**: Actionable tasks queued for the subsequent work session.
6. **Git Commit**: Commit hash and message corresponding to the day's milestone.
