# System Diagrams and Visual Architecture

This directory stores system architecture diagrams, state machine flowcharts, electrical schematics, and mechanical kinematic diagrams.

## Standards
- Editable source files: `.drawio`, `.excalidraw`, `.svg`, or Mermaid markdown.
- Raster exports for README display: `.png` (minimum 300 DPI, transparent or white background).
- Avoid uncompressed BMP or PSD formats.
