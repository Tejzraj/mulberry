# Project Images and Photographic Records

This directory contains photographic documentation of sericulture field visits, mulberry cultivars, manual cutting implements, experimental test benches, and microscopic cut edge evaluations.

## Guidelines
- Maximum individual image size: < 5 MB (compress or downsample before committing).
- File naming: `YYYYMMDD_[SUBJECT]_[DETAIL].jpg` / `.png`
- Maintain high contrast and adequate lighting to preserve visual technical clarity.
