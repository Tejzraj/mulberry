# Video Demonstrations and High-Speed Captures

This directory contains metadata descriptors, frame extractions, and cloud storage links for high-speed cutting footage, machine operation demos, and field trials.

## Storage Policy
- Large video files (`.mp4`, `.mov`, `.avi` > 50 MB) are excluded by `.gitignore`.
- Small optimized animations (`.gif`, `.webp` < 10 MB) demonstrating mechanical linkages or UI flows may be committed.
- Full-length benchmark videos must be uploaded to YouTube (Unlisted), Zenodo, or Google Drive, with markdown links and descriptions recorded in this directory.
