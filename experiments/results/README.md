# Experimental Results and Synthesis Reports

This directory stores formal post-experiment analytical reports and statistical evaluations.

## Structure of a Results Report
1. **Experiment ID and Reference**: Links to the originating protocol in `protocols/`.
2. **Executive Summary**: Core outcome (Hypothesis Supported / Rejected / Inconclusive).
3. **Statistical Analysis**: Descriptive statistics (mean, median, standard deviation), ANOVA / Student's t-test outputs ($p$-values).
4. **Data Visualizations**: Graphs, scatter plots, and frequency spectra.
5. **Engineering Action Items**: Modifications to CAD designs, motor sizing, or algorithms necessitated by the findings.
