# Experimental Protocols Directory

This directory stores standardized, versioned experimental test procedures.

## Naming Convention
`EXP-[DOMAIN]-[INDEX]_[SHORT_NAME].md`
- Example: `EXP-BIO-01_leaf_desiccation.md`
- Example: `EXP-MECH-01_stem_shear_testing.md`
- Example: `EXP-SENS-01_motor_current_signature.md`

All protocols must follow the standard structure documented in [`docs/07-research/experiments.md`](../../docs/07-research/experiments.md).
