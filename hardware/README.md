# Hardware Engineering

This directory contains the physical design documentation, component specifications, bill of materials (BOM), electrical schematics, and mechanical CAD models for the smart mulberry cutting machine.

## Structure
- [`components.md`](components.md) — Technical selection criteria and catalog of candidate hardware components (motors, sensors, controllers, blades).
- [`bill-of-materials.md`](bill-of-materials.md) — Costed preliminary and prototype Bill of Materials.
- [`schematics/`](schematics/README.md) — Electrical wiring diagrams, PCB layouts, power distribution, and sensor interfacing schematics.
- [`mechanical/`](mechanical/README.md) — 2D engineering drawings, 3D CAD models (STEP/STL/DXF), frame layouts, and cutter drum assemblies.
