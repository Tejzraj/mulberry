# Mechanical CAD Models and Engineering Drawings

This directory contains the 3D computer-aided design (CAD) assemblies, component part models, and 2D engineering drawings for the machine frame, cutting chamber, blade drum, and feed chutes.

## File Formats & Standards
- Universal 3D Exchange: `.step` / `.stp` (ISO 10303).
- 2D Manufacturing Drawings: `.dxf` / `.pdf` formatted with GD&T (Geometric Dimensioning and Tolerancing) according to ASME Y14.5M.
- Mesh exports for rapid 3D printing prototyping: `.stl`.

## Subdirectory Conventions
- `assemblies/`: Master top-level mechanical assembly models.
- `parts/`: Individual manufactured or machined component models (shafts, ledger bar, blade holders).
- `drawings/`: Dimensioned manufacturing shop drawings with specified surface roughness and tolerances.
