# Reference Documents and Standards Archive

This directory stores copies, executive summaries, and extracts of official standards, manuals, and institutional bulletins:
- Bureau of Indian Standards (BIS) specifications
- International Organization for Standardization (ISO) guidelines
- Central Silk Board (CSB) technical guidelines
- CSRTI Mysore training manuals

All items are formally indexed in [`docs/07-research/references.md`](../../docs/07-research/references.md).
