# Patent Publications Archive

This directory stores public patent specifications, search query exports, and legal claims analyses for prior-art benchmarking.

## Organization
- Naming format: `[COUNTRY_CODE]_[PATENT_NUMBER]_[APPLICANT]_[TITLE].pdf` / `.md`
- Cross-referenced in `docs/06-patent/prior-art.md`.
- Focus jurisdictions: India (InPASS), WIPO (PCT), China (CNIPA), USA (USPTO), Europe (EPO).
