# Academic & Technical Papers Archive

This directory stores copies, executive summaries, and annotated notes of peer-reviewed journal articles, conference papers, and institutional technical bulletins relevant to mulberry cutting dynamics, sericulture automation, and agricultural robotics.

## Organization
- File naming convention: `[YEAR]_[FIRST_AUTHOR]_[SHORT_TITLE].pdf` / `.md`
- Every paper archived must have a corresponding entry in `docs/07-research/references.md`.
- No pirated or copyrighted material should be checked into public repositories; store bibliographic metadata, Open Access links, and structured markdown synthesis summaries.
